# 王任飞｜游戏策划作品集

打开 `index.html` 预览首页，或在本目录运行 `python -m http.server 8765`，浏览 `http://127.0.0.1:8765/`。

网页简历位于 `resume.html`，支持 A4 打印。作品案例位于 `cases/`。样式和少量交互脚本位于 `assets/`。网站没有构建或运行时依赖，页面、图片和样式都采用相对路径。

## GitHub Pages

把此目录的内容提交到 GitHub 仓库的 `main` 分支。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，来源设为 `main` 和 `/(root)`。发布后以 Pages 设置中显示的链接为准。

作品封面来自《赤栅协议》公开 TapTap 页面。其余机制图是作品集示意。案例文案根据本人简历、公开作品和策划资料重新整理。
